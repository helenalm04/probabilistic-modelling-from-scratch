# GitHub Upload Steps

1. Create a new GitHub repository named `probabilistic-modelling-from-scratch`.
2. Keep the repository private while you review the code and data.
3. Upload the full project folder.
4. Open the notebooks locally and run them once from top to bottom.
5. After confirming everything runs, decide whether to make the repository public.

Suggested first commit message:

```text
Initial portfolio project: probabilistic modelling from scratch
```

Recommended repository description:

```text
NumPy/SciPy implementations of Bernoulli mixture models and Gaussian Process regression, with model comparison and visualisation.
```
