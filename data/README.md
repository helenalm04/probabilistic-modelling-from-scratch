# Data

This folder contains the one-dimensional numeric signal used in the Gaussian Process regression notebook.

```text
data/hr2.txt
```

The file contains scalar observations. In the notebook, the series is mean-centred before fitting Gaussian Process models.

To reuse the notebook with your own data, replace `hr2.txt` with another one-dimensional numeric text file and keep the same filename, or update the data-loading cell.
